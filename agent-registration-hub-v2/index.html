時程討論

整理 10/29 Agent 代客報名第一階段適用範圍，以及 Course / Paid Seminar 的後續上線排期建議。

10/29｜第一階段適用範圍

依目前規劃，先支援基本 seminar 類型；Course 與 Paid Seminar 依實際活動週期與影響範圍排到後續 phase。

● 10/29 Scope
活動情境 建議是否支援代客報名 說明
免費 Seminar＋不需審核 ✅ 適用
免費 Seminar＋需審核
（如：高資產講座）		 ✅ 適用 表單欄位由 Agent 代客戶填寫；若不符合資產要求，審核不通過，報名失敗。
付費 Seminar
（如：老闆台灣講座）		 延後至下一次售票前 需支援付款方式選擇（Agent 一次付清或轉交客戶付款）、新增 To B Shopify Link（Single-use link），以及客戶付款通知流程。
線上 Seminar ✅ 適用 會議連結只寄給 Agent，由 Agent 自行轉達給客戶。
Course－CPA / EA 延後至下一次售票前 需要保留客戶個資、執照號碼、agent 介紹來源，並給學分。
不公開 Seminar ❌ 不適用 目前通常由主辦方邀約，受邀者才能入場。
Agent Only ❌ 不適用 Agent 自己報名。
Summit（付費） ❌ 不適用 使用既有售票 / 團票方式進行。

上線時程討論

依活動舉辦週期與實際使用時點，建議分階段上線，不需將所有情境綁在 10/29 一次完成。

● Rollout Plan
  • Phase 2 與 Phase 3 目前活動舉辦週期較長，約半年一次或單月一次，影響人數相對較小，因此可往後排。
  • 若強趕 10/29 上線，短期內也不會馬上使用到；此外，目前初步規劃完成的 Scope 不包含在原先預估範圍內，需要 RD 另外估時，並採分階段上線。
  1. 10/29｜Phase 1：涵蓋基本 Seminar 代客報名。
  2. 11 月底前｜Phase 2：涵蓋 Course 代客報名。
  3. 12 月底前｜Phase 3：涵蓋 Paid Seminar 代客報名。
