整理 10/29 Agent 代客報名第一階段適用範圍，以及 Paid Seminar / Course 的後續上線時程。

10/29｜第一階段適用範圍

依目前規劃，先支援免費 Seminar 與線上 Seminar；Paid Seminar、Course 及其他特殊活動類型延後。

● 10/29 Scope
活動情境 建議是否支援代客報名 說明
免費 Seminar＋不需審核 ✅ 適用 可直接沿用 Agent 代客報名流程。
免費 Seminar＋需審核
（如：高資產講座）		 ✅ 適用 表單欄位由 Agent 代客戶填寫；若不符合資產要求，審核不通過，報名失敗。
付費 Seminar
（如：老闆台灣講座）		 延後至下一次售票前 付款通知改為提供選擇：
1. Agent 代客戶付款，不需留下客戶 Email。
2. 客戶自行付款，需留下客戶 Email，系統提供 To B Shopify 付款連結。
線上 Seminar ✅ 適用 會議連結只寄給 Agent，由 Agent 自行轉達給客戶。
Course－CPA / EA 延後上線 需要保留客戶個資、執照號碼、Agent 介紹來源等課程專屬資料。
不公開 Seminar ❌ 不適用 目前通常由主辦方邀約，受邀者才能入場。
Agent Only ❌ 不適用 Agent 自己報名。
Summit（付費） ❌ 不適用 維持 Summit 既有售票 / 團票流程。
