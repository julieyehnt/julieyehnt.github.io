Paid Seminar｜Agent 代客報名功能流程與範疇

此頁整理本次 Paid Seminar 代客報名的後台設定、前台付款選擇，以及 To C / To B 三種通知信流程。

1. 後台建立 Paid Seminar

  • Paid Seminar 可分別設定 To C Shopify marketplace link 與 To B Shopify marketplace link。
  • To C link：沿用現況，提供一般客戶自行報名後付款。
  • To B link：本次新增，適用 Agent 代客報名情境；審核通過後依付款對象帶入此連結。

2. 前台 Agent 代客報名

  • Agent 進入代客報名後，先選擇付款方式。
  • Agent 自行付款：不需填寫客戶 Email。
  • 客戶自行付款：每位客戶 Email 必填，系統用於寄送付款連結。
